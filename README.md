# Constellation Whale

A constellation whale brings the wonder of the ocean into the vastness of space. The square artwork is supplied as a 1024 × 1024 JPEG, preserved byte-for-byte under the required filename `entry.png`.

Run with Node 22: `node main.ts`. The program copies the artwork to `/output/entry.png`, or to the directory specified by `MAKEFUN_OUTPUT_DIR`.
