# Constellation Whale

A gigantic translucent whale made of glowing constellations swims across an indigo night sky above a tiny coastal town, trailing a river of golden light. The original 1024px JPEG is copied byte-for-byte by the entry program, preserving the artwork exactly for the judge.

Competition: [Make the AI judge excited](https://make.fun/bounty/ai-excited-01)
